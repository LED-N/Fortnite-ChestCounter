# Fortnite Chest Counter

**フォートナイトで開けた宝箱を、試合ごとに自動集計。ゲーム中はオーバーレイで確認できます。**

Windows 10 / 11 · `ChestCounter.exe` 単体で利用可能

</div>

Chest Counter は、フォートナイトが保存したリプレイから、自分で開けた・破壊した宝箱と、その宝箱から受け取ったトレジャーハントのお宝を集計します。常に手前に表示するオーバーレイと、ブラウザーで開く詳細レポートを利用できます。

## 日本語で起動する

1. このブランチを取得し、.NET 10 SDKをインストールした環境で `build.bat` を実行します。生成された `dist\ChestCounter.exe` を使用してください。日本語対応を含まない旧リリースとは区別してください。
2. フォートナイトの設定でリプレイの録画を有効にします。
3. `ChestCounter.exe` を起動し、最初の言語選択で **日本語** を選びます。矢印キーで選択し、Enter で決定します。
4. リプレイフォルダーの確認、既存リプレイの集計、フォートナイトとの自動起動を設定します。
5. プレイ中はツールを起動したままにします。最小化して構いません。

初回設定または **C** キーの設定画面から変更できるため、BATやコマンドの指定は不要です。コマンドから明示的に指定することもできます：

```powershell
.\ChestCounter.exe --lang ja
```

言語は保存され、次回以降も日本語になります。起動後は **C** キーの設定から変更できます。日本語の Windows では初回の言語選択も日本語が初期候補になります。

## 集計の仕組み

通常のリプレイ保存先は `%LOCALAPPDATA%\FortniteGame\Saved\Demos` です。ツールはリプレイファイルを読み取り専用で開き、ゲームのインストールファイルやメモリーにはアクセスしません。ログインや Epic アカウントへのアクセスも不要です。

暗号化リプレイの復号鍵は通常、試合終了時に保存されます。試合中は **● 試合中** と表示され、終了後に解析可能になると集計結果が反映されます。空の鍵や全ゼロの鍵を持つファイルは復号できないため、書き込みが終わるまで待機・再試行します。鍵が保存されないままの不完全なリプレイは集計できません。

通信は GitHub の更新確認・ダウンロードで使用します。設定から更新確認を無効にできます。

## オーバーレイ

- 大きな数字：宝箱の合計と、現在または前の試合の宝箱数。
- 今回の起動：起動後の宝箱数、試合数、平均。
- 前の試合：直前の試合の宝箱数。
- お宝：見つけたお宝の合計。

ゲーム上に表示するには、フォートナイトのウィンドウモードを **ウィンドウフルスクリーン** に設定してください。大きさ（70～175%）と不透明度（30～100%）は **C** キーの設定で変更できます。配信では `overlay.html` を OBS のブラウザーソースに指定できます。

## ショートカット

| キー・操作 | 内容 |
|---|---|
| Ctrl+Shift+O | オーバーレイの表示・非表示。ゲーム中も使用可能。 |
| Ctrl+Shift+L | オーバーレイをロック・解除。ロック中はマウス操作が背後に届きます。 |
| オーバーレイを左ドラッグ | ロック解除中に移動。 |
| オーバーレイを右クリック | 非表示。 |
| 鍵アイコンをクリック | オーバーレイをロック。 |
| R | レポートを開く。 |
| O / L | 表示切替 / ロック切替。 |
| P | プロフィールを切り替える。 |
| C | 言語、自動起動、更新、オーバーレイ、リプレイフォルダーなどの設定。 |
| U | 更新を確認し、新しいバージョンがあればインストール。 |
| S / H / Q | 集計 / ヘルプ / 終了。 |

英字1文字のキーはツールのウィンドウ内で使います。

## レポートとお宝

`report.html` はブラウザーで開き、自動更新されます。合計、平均、最高記録、日別・種類別の集計、お宝の入手元、最近の試合を確認できます。弾薬箱・食料箱・戦利品キャノンは別集計で、宝箱の合計には含みません。

- **★★**：報酬IDを持つ金色の宝箱から確実に検出したお宝。
- **★**：自分の宝箱から受け取ったお宝。入手時刻を表示し、識別できた場合は名前も表示します。正確な種類が分からない場合は「お宝アイテム（種類不明）」になります。
- **⚑**：宝箱以外から入手したお宝。

報酬の名前は `treasures.json` で編集できます。編集済みの名前は言語を変更しても保持されます。履歴に保存されている宝箱・アイテムの内部名称も維持し、画面表示時に翻訳します。

## プロフィール・自動起動・更新

複数アカウントのリプレイがある場合は、アカウントごとのプロフィールで集計します。起動時や **P** キーで切り替えられます。

「フォートナイトと一緒に起動」を有効にすると、Windows 起動時に待機プロセスが動き、フォートナイト起動時にカウンターを開きます。ゲーム終了後は最後の試合を集計してから終了します。設定から無効にできます。

更新後も履歴と設定は引き継がれます。更新方法は、確認してからインストール・自動インストール・無効から選べます。

## 保存データ

保存先：`%APPDATA%\ChestCounter`

| ファイル | 内容 |
|---|---|
| `report.html` | 詳細レポート。 |
| `overlay.html` | OBS 用の透過背景オーバーレイ。 |
| `matches.csv` | Excel などで利用する試合一覧。 |
| `data.json` | 全履歴。PC 移行時はバックアップしてください。 |
| `config.json` | 言語・プロフィール・表示などの設定。 |
| `treasures.json` | 編集可能な報酬名。 |
| `errors.log` | 読み取れないリプレイの詳細。 |

設定をやり直すには `ChestCounter.exe --reset-config` を実行します。

## 困ったとき

**集計されない**：リプレイ録画が有効か、試合終了時にツールが起動しているか、保存先が正しいか確認してください。クリエイティブなど、バトルロイヤル以外のモードは集計対象外です。

**試合途中でゲームが終了した**：復号鍵が保存されない不完全なリプレイは解析できません。

**リプレイを読み取れない**：ゲーム更新で形式が変わった可能性があります。[Issue](../../issues) に状況と `errors.log` を添付してください。既存の集計結果は保持されます。

**二重集計されるか**：同じリプレイは、名前を変更しても二重に集計しません。

## コマンドライン

```text
ChestCounter.exe --lang <fr|en|es|ja>           言語を指定
ChestCounter.exe --demos <folder>              リプレイフォルダーを指定
ChestCounter.exe --data <folder>               データ保存先を指定
ChestCounter.exe --once                        終了済みリプレイを解析して終了
ChestCounter.exe --reset-config                初期設定をやり直す
ChestCounter.exe --overlay-preview <file.png>  オーバーレイ画像を保存して終了
```

## ソースからビルドする

Windows x64 用の [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) をインストールして `build.bat` を実行します。出力先は `dist\ChestCounter.exe` です。
